# FreshMart - Odoo eCommerce Theme for Grocery Stores

## Overview
FreshMart is a modern, responsive, and feature-rich Odoo 18 theme specifically designed for online grocery stores and supermarkets. This theme offers a seamless shopping experience with optimized product displays, quick category navigation, and an intuitive checkout process.

## Features

### 🛒 Product Showcase
- Beautiful product grid and list views
- Quick view functionality
- Product variations and attributes
- Stock availability indicators
- Special offers and discount badges

### 🏪 Category Management
- Multi-level category navigation
- Category banners and thumbnails
- Featured categories on homepage
- Easy category filtering

### 🛍️ Shopping Experience
- One-page checkout process
- Multiple payment gateways
- Delivery time slots
- Order tracking
- Wishlist functionality

### 🎨 Design Elements
- Clean and modern UI/UX
- Fully responsive design
- Customizable color schemes
- Beautiful product animations
- Optimized for fast loading

## Installation

1. Install the module through Odoo Apps or manually by placing the `theme_fresh_mart` folder in your Odoo addons directory
2. Go to Apps > Update Apps List
3. Search for "FreshMart" and click Install
4. Go to Website > Configuration > Settings and select FreshMart as your theme

## Configuration

1. **Customize Theme**
   - Navigate to Website > Customize Theme
   - Adjust colors, fonts, and layout options
   - Upload your store logo and favicon

2. **Set Up Categories**
   - Go to Website > eCommerce > Categories
   - Create and organize your product categories
   - Upload category images and set display preferences

3. **Configure Payment Methods**
   - Go to Website > eCommerce > Configuration > Payment Providers
   - Enable and configure your preferred payment gateways
